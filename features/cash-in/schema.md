# Schema

## Database Cash

### Cash Header

| Kolom         | Kolom Frontend                                                                                                | Requirement                                                                                                                      | Tujuan                                                                                                                                                                                                   | Sample Data                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| id            | tidak ditampilkan                                                                                             | Primary key, auto increment, unsigned integer                                                                                    | Nomor pengenal unik untuk sistem saja. User tidak pernah melihat atau mengisi ini                                                                                                                        | 1, 2, 3, 4, 5                                                    |
| formulir\_id  | Form Number                                                                                                   | Wajib diisi · unsigned int · FK → formulir.id · ON UPDATE cascade · ON DELETE cascade                                            | Nomor bukti transaksi yang bisa dicari & dilacak di halaman List/Detail. Contoh: `CASH-IN/0004/VIII/26`                                                                                                  | 101, 102, 103, 104, 105                                          |
| coa\_id       | Cash Account                                                                                                  | Wajib diisi · unsigned int · FK → coa.id · ON UPDATE cascade · ON DELETE cascade                                                 | Kas mana yang dipakai — misalnya Kas Besar (untuk transaksi nominal besar) atau Kas Kecil Operasional (untuk transaksi harian). Ini yang muncul di dropdown "Cash Account" saat user buat transaksi baru | 10122, 10130                                                     |
| person\_id    | Payment From                                                                                                  | Wajib diisi · unsigned int · FK → person.id (idx: point\_finance\_cash\_person\_index) · ON UPDATE restrict · ON DELETE restrict | Siapa pihak yang terlibat: customer yang **membayar tunai** (untuk Cash In)                                                                                                                              | 501, 502, 503, 504, 505                                          |
| payment\_flow | bukan field langsung; menentukan kolom List — Received atau Disbursed — tempat nominal baris ini ditampilkan) | Wajib diisi · string · nilai yang diharapkan: "in" atau "out" (divalidasi di level aplikasi — bukan enum di database)            | Penanda apakah ini uang **MASUK** atau **KELUAR**. Inilah yang membuat nominal transaksi muncul di kolom **Received** atau **Disbursed** pada halaman List                                               | "out", "out", "in", "out", "in"                                  |
| total         | Amount                                                                                                        | Wajib diisi · decimal(16,4)                                                                                                      | Jumlah total uang dalam transaksi ini. **Dihitung otomatis** dari penjumlahan semua baris rincian akun di bawahnya — user tidak perlu isi manual, sistem yang jumlahkan.                                 | 310000.0000, 320100.0000, 2500000.0000, 313600.0000, 750000.0000 |

### Cash Detail

| Kolom                    | Kolom Frontend    | Tujuan                                                                                                                                                                                                 | Requirement                                                                                                                          | Sample Data                                                                      |
| ------------------------ | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| id                       | tidak ditampilkan | Nomor pengenal unik baris untuk sistem saja                                                                                                                                                            | Primary key, auto increment, unsigned integer                                                                                        | 1, 2, 3, 4, 5                                                                    |
| point\_finance\_cash\_id | tidak ditampilkan | Menghubungkan baris rincian ini ke transaksi (Header) induknya. Kalau Header-nya dihapus, semua baris rincian di bawahnya ikut terhapus otomatis.                                                      | Wajib diisi · unsigned int · FK → point\_finance\_cash.id (idx: point\_finance\_cash\_index) · ON UPDATE cascade · ON DELETE cascade | 1, 1, 1, 2, 2                                                                    |
| coa\_id                  | Account           | Akun akuntansi spesifik untuk baris ini — misalnya "Beban Bensin Kendaraan" atau "Piutang Usaha". **Beda dengan Cash Account di Header** — ini akun biaya/pendapatan per rincian, bukan sumber kasnya. | Wajib diisi · unsigned int · FK → coa.id · ON UPDATE restrict · ON DELETE restrict                                                   | 53101, 53106, 53103, 41001, 53115                                                |
| allocation\_id           | Allocation        | Alokasi untuk setiap dana yang dikeluarkan                                                                                                                                                             | Opsional·                                                                                                                            | 1, 1, 2, (dalam praktiknya nullable untuk baris cash-in — lihat Catatan)         |
| notes\_detail            | Notes             | Catatan bebas menjelaskan baris ini, misalnya "Bensin mobil box" atau "Pelunasan invoice INV-2201"                                                                                                     | Opsional · text                                                                                                                      | "Testing", "Bensin mobil box kiriman HB Mojokerto", "Pelunasan invoice INV-2201" |
| amount                   | Amount            | Nominal untuk baris rincian ini secara spesifik. Semua Amount di sini otomatis dijumlahkan menjadi Total di Header.                                                                                    | Wajib diisi · decimal(16,4)                                                                                                          | 100000.0000, 120100.0000, 200000.0000, 2500000.0000, 313600.0000                 |
