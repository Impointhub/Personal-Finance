# Schema

## Bank Header

| Kolom         | Kolom Frontend                                                                                                   | Requirement                                                                                                                      | Contoh Data                                                      | Tujuan                                                                                                                                                                      |
| ------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id            | -                                                                                                                | Primary key, auto increment, unsigned integer                                                                                    | 1, 2, 3, 4, 5                                                    | Pengenal unik untuk setiap header transaksi bank (satu baris untuk satu form pembayaran/penerimaan).                                                                        |
| formulir\_id  | Form Number                                                                                                      | Wajib diisi · unsigned int · FK → formulir.id · ON UPDATE cascade · ON DELETE cascade                                            | 201, 202, 203, 204, 205                                          | Menghubungkan transaksi bank ini ke record formulir sumbernya (nomor dokumen/seri yang menjadi induknya).                                                                   |
| coa\_id       | Bank Account                                                                                                     | Wajib diisi · unsigned int · FK → coa.id · ON UPDATE cascade · ON DELETE cascade                                                 | 20122, 20130                                                     | Akun Chart of Account yang dipakai sebagai akun bank di level header (rekening bank asal/tujuan uangnya).                                                                   |
| person\_id    | Payment To /                                                                                                     | Wajib diisi · unsigned int · FK → person.id (idx: point\_finance\_bank\_person\_index) · ON UPDATE restrict · ON DELETE restrict | 501, 502, 503, 504, 505                                          | Pihak lawan transaksi (customer atau supplier) yang menerima pembayaran atau memberikan penerimaan ini.                                                                     |
| payment\_flow | — (bukan field langsung; menentukan kolom List — Received atau Disbursed — tempat nominal baris ini ditampilkan) | Wajib diisi · string · nilai yang diharapkan: "in" atau "out" (divalidasi di level aplikasi — bukan enum di database)            | "out", "out", "in", "out", "in"                                  | Membedakan bank-out (uang keluar/pembayaran) dan bank-in (uang masuk/penerimaan). Menentukan apakah nominal ditampilkan di kolom Disbursed atau Received pada halaman List. |
| total         | Amount (halaman List) / Total (halaman Detail, baris bawah tabel line-item)                                      | Wajib diisi · decimal(16,4)                                                                                                      | 310000.0000, 320100.0000, 2500000.0000, 313600.0000, 750000.0000 | Total nominal transaksi — jumlah di level header yang ditampilkan pada halaman List dan Detail.                                                                             |

## Bank Detail

| Kolom                    | Kolom Frontend                                                                                                   | Requirement                                                                                                                          | Contoh Data                                                                      | Tujuan                                                                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| id                       | — (tidak ditampilkan)                                                                                            | Primary key, auto increment, unsigned integer                                                                                        | 1, 2, 3, 4, 5                                                                    | Pengenal unik untuk setiap baris item dalam satu transaksi bank.                                                                                             |
| point\_finance\_bank\_id | — (tidak ditampilkan langsung; mengelompokkan baris pada tabel line-item)                                        | Wajib diisi · unsigned int · FK → point\_finance\_bank.id (idx: point\_finance\_bank\_index) · ON UPDATE cascade · ON DELETE cascade | 1, 1, 1, 2, 2                                                                    | Mengelompokkan baris item ini di bawah header transaksi induknya — satu header bisa memiliki banyak baris detail (tabel akun yang tampil di halaman Detail). |
| coa\_id                  | Account                                                                                                          | Wajib diisi · unsigned int · FK → coa.id · ON UPDATE restrict · ON DELETE restrict                                                   | 53101, 53106, 53103, 41001, 53115                                                | Akun beban/pendapatan spesifik yang dibebankan pada baris item ini (akun per baris, berbeda dari akun bank di header).                                       |
| allocation\_id           | Allocation                                                                                                       | opsional· unsigned int · FK → allocation.id · ON UPDATE restrict · ON DELETE restrict                                                | 1, 1, 2, (dalam praktiknya nullable untuk baris bank-in — lihat Catatan)         | Cost center / cabang / alokasi tempat baris item ini dibebankan.                                                                                             |
| notes\_detail            | Notes                                                                                                            | opsional · text                                                                                                                      | "Testing", "Bensin mobil box kiriman HB Mojokerto", "Pelunasan invoice INV-2201" | Catatan bebas yang menjelaskan peruntukan baris item ini.                                                                                                    |
| amount                   | Amount                                                                                                           | Wajib diisi · decimal(16,4)                                                                                                          | 100000.0000, 120100.0000, 200000.0000, 2500000.0000, 313600.0000                 | Nominal untuk baris item ini secara spesifik.                                                                                                                |
| reference\_id            | — (tidak ditampilkan langsung; dipakai misalnya untuk menghubungkan nomor invoice atau baris Cash Advance Usage) | Opsional · integer, nullable · terindeks                                                                                             | NULL, NULL, 2201, NULL, NULL                                                     | Referensi polymorphic ke record terkait yang sedang dilunasi oleh baris ini (misalnya invoice atau cash advance).                                            |
| reference\_type          | — (tidak ditampilkan langsung)                                                                                   | Opsional · string, nullable · terindeks                                                                                              | NULL, NULL, "invoice", NULL, NULL                                                | Model/tabel yang menjadi tujuan reference\_id.                                                                                                               |
